# 🐺 Jarvis — Low-End AI Assistant

> An evolving personal AI assistant project focused on voice interaction, local AI, computer control, and eventually autonomous interaction with the operating system.

Jarvis is my ongoing experiment in building an AI assistant from the ground up.

The project started as a simple Windows voice assistant and is gradually evolving toward a more capable AI system that can understand speech, reason about tasks, interact with the computer, use tools, and eventually operate much more independently.

> 🚧 **Sneak Peek:** I am currently working toward creating an **Arch-based AI operating system**. Due to hardware limitations on my end, development will take some time. Stay tuned!

---

# 📚 Versions & Guides

Each folder in this repository represents a different stage of Jarvis.

## 🟢 01 — Jarvis: Just an AI Voicebot

A simple Windows voice assistant using **Whisper** for speech recognition, an AI provider for generating responses, and **Piper / pyttsx3** for speech output.

📁 `Jarvis_Bare_Minimum/`

# 🚀 Project Vision

The long-term goal of Jarvis is to build an AI assistant that can interact with a computer naturally instead of being limited to a text chat window.

The idea is:

```text
                 ┌─────────────────┐
                 │      USER       │
                 └────────┬────────┘
                          │
                     Voice / Text
                          │
                          ▼
                 ┌─────────────────┐
                 │      JARVIS     │
                 │                 │
                 │  Understand     │
                 │  Reason         │
                 │  Plan           │
                 │  Remember       │
                 └────────┬────────┘
                          │
                    Tools / Actions
                          │
          ┌───────────────┼───────────────┐
          ▼               ▼               ▼
      Computer         Browser         External
       Control         Control          Services
          │               │               │
          └───────────────┼───────────────┘
                          │
                          ▼
                       RESULT
```
